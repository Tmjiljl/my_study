# Contributing / 参与贡献

Thanks for helping make learning tools more accessible. / 感谢参与改进开源学习工具。

1. Open an issue before proposing large changes, describing the learner problem.
2. Fork the project and work on a focused branch.
3. Run `npm test` using Node.js 20 or newer.
4. Open a pull request with motivation, screenshots for UI changes, and tests when relevant.
5. Keep all contributions accessible and privacy-first. Don't submit real learner personal data.

Maintainers should review contributions, respond to issues, and cut tagged releases. Be candid about roadmap and project adoption.
