# Study Hub · 考研学习管理系统

[在线使用](https://xilien-study-hub.glossymesa32.chatgpt.site) · [下载源码包](./study-hub-source-2026-10-29.zip)

此目录保存 2026-10-29 上传的 Study Hub 源码包，原文件名为 `study-hub-源码.zip`。压缩包包含页面、学习任务、错题、学习记录、专注计时、登录与同步接口，以及运行说明。

源码不包含线上数据库、个人学习档案、登录凭据或已安装依赖。解压后请阅读 `源码使用说明.md` 和 `README.md`。完整的登录与云端同步依赖 ChatGPT Sites 的身份与存储环境；GitHub Pages 不能直接运行这些服务端接口。

当前线上发布为 ChatGPT Site 第 18 版，包含英语单词学习与间隔复习板块。上方源码包是 2026-10-29 的历史快照，未包含此后新增的单词板块。仓库中的 RecallKit 是另一个独立应用。
